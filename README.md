# Expense Lens

## Project Overview

Expense Lens is a Python-based personal expense management system developed to help users record, manage, and analyze their daily expenses.

The project allows users to set a monthly budget, add expenses with categories, view total expenses, analyze category-wise spending, delete expenses, and save expense data using JSON file handling.

An Object-Oriented Programming (OOP) version is also included to demonstrate the use of classes, objects, methods, and encapsulation.

## Features

- Set a monthly budget
- Add new expenses
- Categorize expenses
- View all recorded expenses
- Calculate total expenses
- Analyze expenses category-wise
- Delete expenses
- Display budget warnings
- Save expense data using JSON
- Load previously saved expenses
- OOP-based implementation

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```text
expense_lens.py
or

```text
expense_lens_oops.py
5. Enter the monthly budget.
6. Use the menu to add, view, analyze, or delete expenses.
